Autonomous Warehouse Robot Navigation

A robot operating inside an Amazon-style warehouse must navigate a grid of shelves, avoid obstacles, and deliver packages to a goal location — a classic sequential decision-making problem perfectly modelled as a Finite MDP.

Formal Model

Finite MDP Definition

A Markov Decision Process is a tuple (S, A, P, R, γ). Below is the complete formal specification for the Warehouse Robot problem.

S
State Space
|S| = 25 states: {(r,c) | r,c in {0,1,2,3,4}}.
Terminal states: Goal (4,4), Trap (1,2).
A
Action Space
A = {Up, Down, Left, Right}
|A| = 4 actions in every non-terminal state.
P
Transition Model
Stochastic: P(s'|s,a) =
0.80 intended direction
0.10 perpendicular slip (x2)
R
Reward Function
R(s,a,s') defined by cell type:
Goal +100 · Trap -50 · Step -1 · Dock +5 · Wall -10
γ
Discount Factor
gamma = 0.9
Balances immediate vs. long-term rewards.

Value Iteration

Bellman Equation & Value Function

The Bellman Optimality Equation finds the optimal value V*(s) for every state by iterating until convergence. Run the animation to see how values propagate backward from the goal.

Bellman Optimality Equation
V*(s) = maxa Σs' P(s'|s,a) · [ R(s,a,s') + γ · V*(s') ]
V*(s) — optimal value of state s maxa — best possible action P(s'|s,a) — transition probability R(s,a,s') — immediate reward γ·V*(s') — discounted future value
Worked Example — Bellman for State (2,2)
1
Setup: State s = (2,2) · γ = 0.9 · Policy action = Right
Neighbors: (2,3)=open, (1,2)=TRAP, (3,2)=open, (2,1)=open
2
Transition probabilities for action Right:
P((2,3)|(2,2), Right) = 0.80  ·  P((1,2)|(2,2), Right) = 0.10  ·  P((3,2)|(2,2), Right) = 0.10
3
Substitute into Bellman (using converged values):
Q((2,2), Right) = 0.80 × [-1 + 0.9 × V*(2,3)] + 0.10 × [-50 + 0.9 × 0] + 0.10 × [-1 + 0.9 × V*(3,2)]

Key Insights
  • The optimal policy routes around the Trap at (1,2), taking a safer longer path when the stochastic slip risk outweighs the shortcut benefit.
  • The greedy distance policy naively moves toward (4,4) and often slips into the Trap, drastically reducing returns.
  • The random policy rarely reaches the goal before hitting the maximum step limit, yielding near-zero or negative returns.
